L29 的知识层共有 **37 个 reviewed species**。课程主线从听写后的词形与接口纠错，转入 TCF 阅读：先判断连接关系和长句角色，再用题干、选项、定位词、关键句和同义替换完成证据驱动的选择；最后把查词、背词与图片听力也变成可执行策略。

## Learning Mainlines

1. **变位与配合**：`produire` 的现在时/过去分词、`pouvoir` 的 futur simple、`mes amis`、`diplômé` 名词化，以及过去分词后置定语。
2. **动词与介词接口**：`oser + infinitif`、`pousser/encourager quelqu'un à faire`、`faire partie de` / `participer à`、`jusqu'à/jusqu'en`、`de quoi parler`。
3. **连接与句法决策**：普通同时、同时对立、纯转折、反转预期的区别；先拆主谓宾，再归位目的、时间、地点和名词补语。
4. **语境词义与错误边界**：`chercher/rechercher/réfléchir`、`cuisine/alimentation`、`concours`、`stage`、`établissement`、`supprimer/surveiller` 等。
5. **TCF 策略**：题干 → 选项 → 定位词 → 关键句 → 同义替换；文本证据优先于常识；查词和背词按任务价值分级；图片听力代入说话者。

## High-Value Decision Families

- `un renseignement` / `une information`：近义换词时冠词随性别改变。
- `quand/lorsque` / `alors que` / `mais, cependant, pourtant` / `au contraire`：分别处理普通同时、同时对立、纯转折和对预期的反转。
- `on` / `les gens, la population`：前者只能作主语，宾语位置用名词短语。
- `faire partie de` / `participer à`：归属与参与使用不同介词。
- `chercher/rechercher` / `réfléchir`：搜寻与思考不可混用。
- `sauf` / `sauf si`：名词例外与条件例外。
- `cuisine` / `alimentation`：窄义烹饪/菜系与广义食品饮食。
- `supprimer` / `surveiller`：删除取消与监督看管。
