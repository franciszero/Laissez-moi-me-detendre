## 二、这道 T2 的“任务合同”

你上次 T1 使用的是：

> 题目约束决定必须写什么，老师板书决定按什么顺序写，真实交际决定还要补什么。

这个方法可以原样保留，但 T2 的交际目标已经改变。T1 是向朋友索取帮助；T2 是向公众讲述、评价并证明自己的判断。fileciteturn0file0

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| `Vous avez participé` | `J’ai participé à… / Je me suis rendu(e) à…` | 必须写成亲身经历。至少交代活动类型，最好再给时间、地点。 |
| `un festival` | `un festival de musique / de cinéma / de gastronomie` | 必须明确是什么活动，不能全文只写 `cet événement`，让读者猜。 |
| `qui ne vous a pas satisfait` | `Malheureusement, cette expérience m’a beaucoup déçu.` | 文章的总体立场必须清楚。不能写了半天，读者仍不知道你满意还是不满意。 |
| `un article sur votre site` | **标题＋文章正文** | 不是邮件，所以不写 `Salut Marie`、`À bientôt`、署名。文章面向公开读者，可以使用 `je` 讲经历，用 `vous` 向读者提出建议。 |
| `partager votre expérience` | `À mon arrivée… / Pendant le festival… / Nous avons dû…` | 需要出现具体过程，而不是只有抽象评价。 |
| `les raisons de votre insatisfaction` | `Tout d’abord… De plus… Enfin…` | 至少展开两个清楚的原因。每个原因都要有事实支撑。 |
| `120–150 mots` | `environ 130–140 mots` | 内容应集中。通常写两个主要问题，比机械罗列五六个问题更容易讲清楚。 |

压缩后，这道题的任务合同是：

> **公开文章＋亲身经历＋明确不满＋至少两个原因＋具体事实＋最终评价或建议**

## 三、T1 和 T2 的根本差别

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **T1：`demander de l’aide`** | `Je cherche un studio. Mon budget est de… Pourrais-tu m’aider ?` | T1 的核心是**传递必要信息并让对方采取行动**。房型、预算和日期属于固定信息槽。 |
| **T2：`partager et justifier`** | `J’ai participé à ce festival, mais l’organisation était décevante. En effet…` | T2 的核心是**提出评价并用经历证明评价**。 |
| **T1 的内容单位** | `[信息]` | 房型、地点、预算、日期，每格填上即可。 |
| **T2 的内容单位** | `[判断] + [事实] + [影响]` | 不能只写 `L’organisation était mauvaise`。必须告诉读者发生了什么，以及它怎样影响了你的体验。 |
| **T1 的读者** | `un ami francophone` | 使用 `tu`，语气私人。 |
| **T2 的读者** | `les lecteurs de votre site` | 面向公众，语气比邮件更像评论或博客文章。 |
| **T1 的结束** | 感谢朋友、期待回复 | `Merci d’avance. Tiens-moi au courant.` |
| **T2 的结束** | 给出最终判断、建议或改进要求 | `Je ne recommande donc pas ce festival en l’état.` |

所以，T2 不能理解成“把 T1 的房型、预算、日期换成几个投诉理由”。它多出了一层关键任务：

> **你不只要说自己不满意，还要让读者相信你的不满意有事实依据。**

## 四、老师的四段结构怎样落到本题

老师板书提供了四个模块：

> `Titre accrocheur → Introduction → Expérience personnelle → Recommandations`

这套框架可以直接使用，但每个模块都要根据当前的“负面节庆体验”重新填充。

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **1. `Titre accrocheur`** | `Un festival très loin de mes attentes !` | 标题直接点出落差或问题。不能照搬正面范文的 `Un séjour m’a changé la vie !`。 |
| **2. `Introduction`** | `Le week-end dernier, j’ai participé à un festival de musique organisé dans le centre de Toronto.` | 介绍活动是什么、何时、在哪里举行。还可以补一句参加前的期待。 |
| **3. `Votre expérience personnelle`** | `Malheureusement, l’organisation était très mauvaise…` | 正文重点。写具体事件，再解释这些事件为什么让你不满意。 |
| **4. `Recommandations`** | `Je déconseille ce festival tant que son organisation ne sera pas améliorée.` | 当前题目是负面体验，因此建议部分可以写“不推荐”、给未来游客建议，或者要求主办方改进。 |

老师课上使用的正面范文，主要展示的是文章顺序和连接词。它不能整篇直接移植，因为本题要求的是：

> **期待 → 落差 → 问题 → 后果 → 评价**

而不是：

> **参加活动 → 获得成长 → 推荐活动**

## 五、题目之外还必须补什么

以下信息并非全部由题目明说，但缺少以后，文章会像一张投诉清单，不像完整经历。

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **活动身份** | `un festival de musique organisé à Montréal` | 读者先要知道你参加了什么。属于必要背景。 |
| **时间与地点** | `samedi dernier, dans un grand parc du centre-ville` | 不需要写得很细，但能让经历落地。 |
| **参加动机或期待** | `J’attendais cet événement avec impatience.` | 有了期待，后面的失望才形成明显反差。 |
| **总体评价** | `Malheureusement, l’expérience a été très décevante.` | 在开头尽快亮明态度，不能拖到最后才说不满意。 |
| **主要问题** | `l’attente, le prix, la programmation, la propreté…` | 选择两个最容易展开的问题。 |
| **具体事实** | `Nous avons attendu plus d’une heure à l’entrée.` | 事实比 `c’était nul` 更有说服力。 |
| **直接后果** | `Nous avons donc manqué le début du concert.` | 说明问题如何损害了体验。 |
| **最终态度** | `Je ne pense pas y retourner l’année prochaine.` | 文章必须收束，不能写完最后一个问题就突然停止。 |

可以分成三层：

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **任务核心** | `article, festival, expérience, insatisfaction, raisons, 120–150 mots` | 题目明说，缺少任何一项都会影响任务完成度。 |
| **连贯信息** | `type, lieu, moment, attentes, déroulement` | 帮助读者理解事情的来龙去脉。 |
| **评价信息** | `conséquences, recommandation, amélioration souhaitée` | 让文章从“描述事故”升级为完整评论。 |

## 六、T2 最重要的微型结构

T1 可以用一个槽放一个信息。T2 的一个“理由槽”必须由三个零件组成：

> **问题判断 → 具体证据 → 对体验造成的后果**

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **问题判断** | `L’organisation à l’entrée était catastrophique.` | 先告诉读者你不满什么。 |
| **具体证据** | `Nous avons dû attendre plus d’une heure sous la pluie.` | 用可以看见的事件证明判断。 |
| **直接后果** | `À cause de ce retard, nous avons manqué le début du premier concert.` | 解释为什么这个问题严重，以及它怎样破坏体验。 |

合在一起就是：

> **Tout d’abord, l’organisation à l’entrée était catastrophique. Nous avons dû attendre plus d’une heure sous la pluie et, à cause de ce retard, nous avons manqué le début du premier concert.**

第二个理由可以继续使用相同结构：

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **问题判断** | `De plus, les prix étaient excessifs.` | 第二个不满理由。 |
| **具体证据** | `Une petite bouteille d’eau coûtait six dollars.` | 不写模糊的“很贵”，直接给商品和价格。 |
| **直接后果** | `Plusieurs visiteurs ont préféré quitter le site pour manger ailleurs.` | 写出价格对游客行为造成的影响。 |

这套三件组是整篇文章最值得反复训练的部分：

> `[problème] + [preuve concrète] + [conséquence]`

## 七、最稳定的文章总骨架

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **标题** | `Une soirée musicale pleine de déceptions !` | 直接体现主题和立场。 |
| **句 1：活动身份** | `Samedi dernier, j’ai participé à un festival de musique à Toronto.` | 回答什么活动、何时、在哪里。 |
| **句 2：参加前期待** | `J’attendais cette soirée avec impatience, car plusieurs artistes connus étaient annoncés.` | 建立“原本期待很高”的背景。 |
| **句 3：总体落差** | `Malheureusement, l’expérience a été loin de mes attentes.` | 明确进入负面评价。 |
| **句 4：第一个问题** | `Tout d’abord, l’entrée était extrêmement mal organisée.` | 提出原因一。 |
| **句 5：证据和后果** | `Après une heure d’attente, nous avons manqué le début du premier concert.` | 证明原因一。 |
| **句 6：第二个问题** | `De plus, les stands de nourriture étaient trop chers et mal approvisionnés.` | 提出原因二。 |
| **句 7：证据和后果** | `À vingt heures, plusieurs plats n’étaient déjà plus disponibles.` | 证明原因二。 |
| **句 8：补充问题或感受** | `Enfin, le manque de toilettes propres a rendu la soirée encore moins agréable.` | 字数允许时补一个较短的问题。 |
| **句 9：最终判断** | `Au final, je ne recommande pas ce festival dans son organisation actuelle.` | 明确回答是否推荐。 |
| **句 10：改进方向** | `J’espère que les organisateurs tiendront compte de ces problèmes l’année prochaine.` | 给出建设性结束。 |

这不是官方规定必须写十句，而是训练脚手架。熟练以后，可以把相邻功能合并：

> `J’attendais ce festival avec impatience, mais l’expérience a été très décevante en raison d’une organisation chaotique et de prix excessifs.`

## 八、压缩成可以记忆的槽位公式

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| `[Titre]` | 一个体现失望、混乱或落差的标题 | 文章格式标志。 |
| `[Festival]` | 类型＋时间＋地点 | 交代经历背景。 |
| `[Attente]` | 为什么参加、原本期待什么 | 制造前后落差。 |
| `[Verdict général]` | 总体不满意 | 尽早表明立场。 |
| `[Problème 1]` | 问题＋证据＋后果 | 主体理由一。 |
| `[Problème 2]` | 问题＋证据＋后果 | 主体理由二。 |
| `[Problème 3 facultatif]` | 一个较短的补充问题 | 字数够才加入。 |
| `[Avis final]` | 是否推荐、是否再参加 | 收束个人评价。 |
| `[Conseil]` | 给主办方或读者的建议 | 对应老师的 `Recommandations`。 |

整篇可以记成：

> **活动是什么 → 我原来很期待 → 实际很失望 → 问题一及后果 → 问题二及后果 → 我是否推荐 → 应该怎样改**

## 九、三段式字数分配

| 法文问题部分 | 法文回答 | 解释 |
|---|---|---|
| **标题** | `Une expérience très décevante !` | 标题保持短，不承担大量信息。 |
| **第一段：约 25—35 词** | 活动身份＋参加动机＋总体评价 | 让读者快速进入场景。 |
| **第二段：约 70—80 词** | 两个主要问题，每个都写证据和后果 | 这是得分核心，不能把字数全花在开头。 |
| **第三段：约 25—30 词** | 最终评价＋建议 | 回答是否推荐，以及希望怎样改进。 |
| **正文目标** | `130–140 mots` | 写到 120 词边缘风险较高；写到 150 词边缘也不方便修改。 |

Le programme promettait des spectacles, des ateliers et des expositions, mais plusieurs activités étaient fermées ou mal indiquées.`                                      | 可写活动取消、指示牌不足、地图不清楚、节目表不准。         |
| `Un festival de danse`       | `La semaine dernière, j’ai assisté à un festival de danse. Les spectacles étaient intéressants, mais la visibilité était mauvaise et la salle était beaucoup trop chaude.`                                                                      | 可写场地、座位、空调、等待、节目拖延。               |
| `Un festival en famille`     | `J’ai emmené mes enfants à un festival familial dans un grand parc. Malheureusement, il y avait trop peu d’activités pour les enfants et presque aucun espace pour se reposer.`                                                                 | 可写活动年龄不合适、安全、厕所、休息区、饮水和高价。        |

### 最适合当前训练的三套

| 法文问题部分                      | 法文回答                         | 解释                                                        |
| --------------------------- | ---------------------------- | --------------------------------------------------------- |
| `Le choix le plus simple`   | `un festival de musique`     | 不满理由最多，`attendre、concert、son、artiste、scène、billet` 都比较常见。 |
| `Le choix le plus concret`  | `un festival de gastronomie` | 容易给出具体数字：六美元一瓶水、等四十分钟、十点前食物售罄。                            |
| `Le choix le plus organisé` | `un festival de cinéma`      | 两个主问题很好安排：场次取消＋信息通知不足。                                    |

# Chunk 2：标题弹药库

标题的作用是告诉读者文章主题和态度。它不需要复杂，但必须比 `Mon festival` 更具体。

## 1. 通用负面标题

| 法文问题部分                        | 法文回答                                                | 解释                       |
| ----------------------------- | --------------------------------------------------- | ------------------------ |
| `Un festival décevant`        | **Un festival très décevant !**                     | 最稳妥，但信息较少。               |
| `Une expérience négative`     | **Une expérience que je ne souhaite pas revivre !** | 强调不会再次参加。                |
| `Des attentes déçues`         | **Un festival loin de mes attentes !**              | 很适合“原本期待很高，实际很差”的结构。     |
| `Une mauvaise organisation`   | **Quand une mauvaise organisation gâche la fête**   | `gâcher` 表示毁掉、破坏。标题比较自然。 |
| `Des problèmes multiples`     | **Entre longues attentes et prix excessifs**        | 直接预告两个主要问题。              |
| `Une recommandation négative` | **Un festival que je ne recommande pas**            | 立场非常清楚，句法简单。             |

## 2. 音乐节标题

| 法文问题部分                        | 法文回答                                                  | 解释                      |
| ----------------------------- | ----------------------------------------------------- | ----------------------- |
| `Un festival de musique`      | **Une soirée musicale pleine de déceptions !**        | 可用于音乐会或音乐节。             |
| `Des concerts en retard`      | **Beaucoup d’attente, très peu de musique !**         | 有对比感，读者能立刻看到核心问题。       |
| `Une mauvaise qualité sonore` | **Un festival où la musique était presque inaudible** | `inaudible` 表示听不清、无法听见。 |
| `Une organisation chaotique`  | **Un festival de musique totalement désorganisé**     | 适合正文主要写秩序和流程。           |

## 3. 美食节标题

| 法文问题部分                      | 法文回答                                                   | 解释                              |
| --------------------------- | ------------------------------------------------------ | ------------------------------- |
| `Un festival gastronomique` | **Un festival gastronomique sans saveur !**            | `sans saveur` 原意是没有味道，也能表达活动乏味。 |
| `Des prix élevés`           | **Des portions minuscules à des prix énormes !**       | 对比鲜明，适合价格和份量问题。                 |
| `Un manque de nourriture`   | **Un festival de gastronomie presque sans nourriture** | 适合写许多摊位提前售罄。                    |

## 4. 电影节标题

| 法文问题部分                       | 法文回答                                                         | 解释                         |
| ---------------------------- | ------------------------------------------------------------ | -------------------------- |
| `Un festival de cinéma`      | **Un festival de cinéma au scénario décevant !**             | 用 `scénario` 做轻微文字游戏。      |
| `Des séances annulées`       | **Des films annoncés, mais jamais projetés !**               | `projeter un film` 表示放映电影。 |
| `Une mauvaise programmation` | **Une programmation qui manque sérieusement d’organisation** | 比较正式，适合 B1—B2 写法。          |

### 标题训练原则

| 法文问题部分                                       | 法文回答                                            | 解释                                                 |
| -------------------------------------------- | ----------------------------------------------- | -------------------------------------------------- |
| `Faut-il écrire une phrase complète ?`       | `Non, un groupe nominal peut suffire.`          | 标题可以是完整句，也可以只是名词短语。                                |
| `Faut-il ajouter un point ?`                 | `Non. On peut utiliser un point d’exclamation.` | 标题通常不加句号。负面体验可以使用感叹号。                              |
| `Faut-il reprendre exactement la consigne ?` | `Non.`                                          | 不要只写 `Mon expérience dans un festival`，这种标题太像题目复述。 |

# Chunk 3：文章开头——活动身份、期待与落差

## 1. 交代时间

| 法文问题部分                                    | 法文回答                                                                       | 解释                               |
| ----------------------------------------- | -------------------------------------------------------------------------- | -------------------------------- |
| `Quand avez-vous participé au festival ?` | `Samedi dernier, j’ai participé à un festival de musique.`                 | `samedi dernier` 不加冠词。           |
| `Quand avez-vous participé au festival ?` | `Le week-end dernier, je suis allé à un festival de cinéma.`               | `le week-end dernier` 要有冠词 `le`。 |
| `Quand avez-vous participé au festival ?` | `Le mois dernier, j’ai assisté à un festival gastronomique.`               | 适合不想编具体日期时使用。                    |
| `Quand avez-vous participé au festival ?` | `Au début du mois de juillet, je me suis rendu à un festival culturel.`    | 更具体，但略长。                         |
| `Quand avez-vous participé au festival ?` | `Il y a quelques semaines, j’ai découvert un nouveau festival de musique.` | `il y a + 时间段` 表示多久以前。           |

## 2. 交代地点

| 法文问题部分                               | 法文回答                                                                     | 解释                             |
| ------------------------------------ | ------------------------------------------------------------------------ | ------------------------------ |
| `Où le festival avait-il lieu ?`     | `Le festival avait lieu dans un grand parc du centre-ville.`             | `avoir lieu` 表示举行。描述活动地点时非常常用。 |
| `Où le festival était-il organisé ?` | `L’événement était organisé près du lac Ontario.`                        | 被动结构，适合交代地点。                   |
| `Où êtes-vous allé ?`                | `Je suis allé au festival organisé sur la place centrale.`               | `organisé` 修饰 `festival`。      |
| `Dans quelle ville ?`                | `J’ai participé à un festival de musique à Montréal.`                    | 城市前用 `à`。                      |
| `Dans quel type de lieu ?`           | `Les activités se déroulaient dans plusieurs salles du centre culturel.` | `se dérouler` 表示进行、举行。         |

## 3. 说明参加动机

| 法文问题部分                                    | 法文回答                                                                      | 解释                                  |
| ----------------------------------------- | ------------------------------------------------------------------------- | ----------------------------------- |
| `Pourquoi avez-vous choisi ce festival ?` | `Plusieurs artistes connus devaient s’y produire.`                        | `se produire` 表示登台演出；`y` 代替在这个节庆现场。 |
| `Pourquoi vouliez-vous y aller ?`         | `Je voulais découvrir de nouveaux réalisateurs francophones.`             | 适合电影节。                              |
| `Pourquoi avez-vous acheté un billet ?`   | `Le programme semblait très intéressant et varié.`                        | `sembler + adjectif` 表示看起来怎样。       |
| `Pourquoi avez-vous participé ?`          | `Mes amis m’avaient beaucoup parlé de cet événement.`                     | 使用愈过去时，表示朋友之前已经介绍过。                 |
| `Pourquoi étiez-vous intéressé ?`         | `J’espérais goûter des spécialités venues de plusieurs pays.`             | 适合美食节。                              |
| `Pourquoi êtes-vous venu en famille ?`    | `Les organisateurs annonçaient de nombreuses activités pour les enfants.` | 后文可写实际活动很少，形成落差。                    |

## 4. 表达期待

| 法文问题部分                                             | 法文回答                                                                                | 解释                                           |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------- |
| `Quelle était votre attente ?`                     | `J’attendais cet événement avec impatience.`                                        | 最通用。`attendre quelque chose` 不加介词。           |
| `Quelle impression aviez-vous avant le festival ?` | `Je pensais passer une excellente soirée.`                                          | `penser + infinitif`：认为自己会做某事。               |
| `Aviez-vous de grandes attentes ?`                 | `Compte tenu du prix du billet, je m’attendais à une organisation professionnelle.` | `s’attendre à` 表示期待、预料。不能写成 `attendre à`。    |
| `Qu’espériez-vous ?`                               | `J’espérais assister à plusieurs concerts de qualité.`                              | `espérer + infinitif`，不加 `de`。               |
| `Étiez-vous enthousiaste ?`                        | `J’étais très enthousiaste à l’idée de découvrir ce festival.`                      | `être enthousiaste à l’idée de + infinitif`。 |
| `Le programme vous attirait-il ?`                  | `Le programme promettait une journée riche en activités.`                           | 后面可以转折：实际很多活动取消。                             |

## 5. 从期待转向失望

| 法文问题部分                                           | 法文回答                                                                                    | 解释                                    |
| ------------------------------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------- |
| `L’expérience a-t-elle répondu à vos attentes ?` | `Malheureusement, l’expérience a été loin de mes attentes.`                             | `être loin de mes attentes`：远低于我的期待。  |
| `Quelle a été votre impression générale ?`       | `Cependant, la réalité était très différente de ce qui avait été annoncé.`              | `ce qui avait été annoncé` 表示先前宣传的内容。 |
| `Étiez-vous satisfait ?`                         | `Dès mon arrivée, j’ai compris que l’organisation laissait à désirer.`                  | `laisser à désirer` 表示不尽如人意。          |
| `Comment résumer votre expérience ?`             | `Cette journée, qui devait être agréable, s’est transformée en une suite de problèmes.` | 适合做较有力度的过渡句。                          |
| `Le festival vous a-t-il plu ?`                  | `À ma grande déception, le festival n’a pas tenu ses promesses.`                        | `tenir ses promesses`：兑现承诺。           |
| `Quelle était votre réaction ?`                  | `Je suis rapidement passé de l’enthousiasme à la frustration.`                          | 表示情绪从兴奋转为挫败。                          |

### 最稳的开头组合

| 法文问题部分                        | 法文回答                                                                                                                                                                                                                      | 解释                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `Introduction simple`         | `Samedi dernier, j’ai participé à un festival de musique à Toronto. J’attendais cet événement avec impatience, car plusieurs artistes connus étaient annoncés. Malheureusement, l’expérience a été loin de mes attentes.` | 三句话完成时间、活动、地点、期待和总体评价。 |
| `Introduction plus naturelle` | `Le week-end dernier, je me suis rendu à un festival gastronomique organisé dans le centre-ville. Le programme semblait varié et prometteur. Pourtant, plusieurs problèmes ont rapidement gâché notre journée.`           | `pourtant` 强调期待与事实相反。  |
| `Introduction plus compacte`  | `Attiré par un programme qui semblait exceptionnel, j’ai participé samedi dernier à un festival de cinéma. Malheureusement, la mauvaise organisation a transformé cette sortie en véritable déception.`                   | 信息密度高，适合需要节省字数时使用。     |

# Chunk 4：不满理由弹药库

## 1. 入场和排队问题

| 法文问题部分                                          | 法文回答                                                                         | 解释                             |
| ----------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------ |
| `Comment était l’entrée ?`                      | `L’entrée était extrêmement mal organisée.`                                  | 总体判断。下一句必须补事实。                 |
| `Combien de temps avez-vous attendu ?`          | `Nous avons dû attendre plus d’une heure avant d’entrer.`                    | `devoir + infinitif` 表示不得不。    |
| `Pourquoi l’attente était-elle pénible ?`       | `Il n’y avait qu’une seule file pour plusieurs centaines de visiteurs.`      | 给出排队慢的具体原因。                    |
| `Dans quelles conditions avez-vous attendu ?`   | `Nous sommes restés debout sous la pluie pendant près de cinquante minutes.` | 场景很具体，可以直接看到画面。                |
| `Les billets ont-ils été vérifiés rapidement ?` | `La vérification des billets avançait très lentement.`                       | `avancer lentement` 可形容队伍处理速度。 |
| `Les informations étaient-elles claires ?`      | `Personne ne savait dans quelle file il fallait attendre.`                   | 说明现场指引混乱。                      |
| `Quelle a été la conséquence ?`                 | `À cause de cette attente, nous avons manqué le début du premier concert.`   | 将排队问题连接到体验损失。                  |
| `Quelle a été votre réaction ?`                 | `Nous étions déjà fatigués et irrités avant même le début du festival.`      | `avant même` 强调活动尚未开始，体验已被破坏。  |

### 可直接背的句组

> **Tout d’abord, l’entrée était très mal organisée. Nous avons dû attendre plus d’une heure sous la pluie, car une seule file était ouverte. À cause de ce retard, nous avons manqué le début du premier concert.**

---

## 2. 节目延误、取消和安排混乱

| 法文问题部分                                         | 法文回答                                                                                             | 解释                                     |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------- |
| `Le programme a-t-il été respecté ?`           | `Le programme annoncé n’a pas été respecté.`                                                     | 可用于任何节庆。                               |
| `Les activités ont-elles commencé à l’heure ?` | `Presque tous les spectacles ont commencé avec du retard.`                                       | `avec du retard` 表示晚点。                 |
| `Un artiste est-il venu ?`                     | `L’un des principaux artistes a annulé sa participation au dernier moment.`                      | 音乐节常用。                                 |
| `Une séance a-t-elle été annulée ?`            | `Deux séances ont été annulées sans explication claire.`                                         | 电影节常用。                                 |
| `Avez-vous été informé ?`                      | `Les visiteurs n’ont reçu aucune information avant l’annulation.`                                | 抱怨通知机制。                                |
| `Le programme était-il fiable ?`               | `Les horaires affichés sur place ne correspondaient pas à ceux du site Internet.`                | 具体、可信。                                 |
| `Que s’est-il passé entre les activités ?`     | `Il y avait parfois plus d’une heure d’attente entre deux spectacles.`                           | 适合节目衔接差。                               |
| `Quelle a été la conséquence ?`                | `Nous avons passé une grande partie de la journée à attendre au lieu de profiter des activités.` | `au lieu de + infinitif`：没有享受活动，反而一直等。 |
| `Avez-vous pu voir tout ce qui était prévu ?`  | `Nous n’avons finalement vu que la moitié des spectacles prévus.`                                | `ne… que` 表示仅仅。                        |

### 可直接背的句组

> **De plus, le programme n’a pas été respecté. Plusieurs concerts ont commencé avec plus de quarante minutes de retard et un artiste a annulé sa participation sans explication. Nous avons donc passé davantage de temps à attendre qu’à écouter de la musique.**

---

## 3. 价格过高

| 法文问题部分                                        | 法文回答                                                                                   | 解释                                          |
| --------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------- |
| `Comment étaient les prix ?`                  | `Les prix pratiqués sur place étaient excessifs.`                                      | `les prix pratiqués` 指商家实际收取的价格。            |
| `Le billet était-il cher ?`                   | `Le billet coûtait déjà soixante dollars, ce qui me semblait très élevé.`              | `ce qui` 指代前面整件事。                           |
| `Combien coûtait l’eau ?`                     | `Une petite bouteille d’eau coûtait six dollars.`                                      | 用具体数字替代 `très cher`。                        |
| `Combien coûtait un repas ?`                  | `Il fallait payer près de vingt dollars pour une portion minuscule.`                   | `il fallait payer` 描述普遍情况。                  |
| `Les prix correspondaient-ils à la qualité ?` | `La qualité des produits ne justifiait absolument pas ces prix.`                       | `justifier un prix`：配得上这个价格。                |
| `Y avait-il des options abordables ?`         | `Aucune option abordable n’était proposée aux visiteurs.`                              | `abordable` 表示价格负担得起。                       |
| `Quelle a été la conséquence ?`               | `Plusieurs familles ont quitté le site pour aller manger ailleurs.`                    | 说明高价直接影响游客行为。                               |
| `Comment vous êtes-vous senti ?`              | `J’ai eu l’impression que les organisateurs cherchaient surtout à gagner de l’argent.` | 表达主观看法时用 `avoir l’impression que`，避免把推测当事实。 |

### 可直接背的句组

> **Les prix constituaient un autre problème. Une bouteille d’eau coûtait six dollars et il fallait payer près de vingt dollars pour un petit repas. Compte tenu du prix déjà élevé du billet, ces tarifs m’ont paru injustifiés.**

---

## 4. 食物不足、份量和质量问题

| 法文问题部分                                                  | 法文回答                                                                                         | 解释                          |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------- |
| `Y avait-il assez de nourriture ?`                      | `Plusieurs stands avaient déjà épuisé leurs plats avant vingt heures.`                       | `épuiser` 在这里表示售罄、用尽。       |
| `Tous les plats étaient-ils disponibles ?`              | `La moitié des spécialités annoncées n’étaient plus disponibles.`                            | 适合美食节。                      |
| `Comment étaient les portions ?`                        | `Les portions étaient beaucoup trop petites par rapport aux prix.`                           | `par rapport à` 表示与……相比。    |
| `Comment était la qualité ?`                            | `Les plats étaient froids et manquaient de fraîcheur.`                                       | `manquer de fraîcheur`：不新鲜。 |
| `Combien de temps fallait-il attendre ?`                | `Nous avons attendu quarante minutes pour recevoir un plat froid.`                           | 排队和质量双重问题。                  |
| `Y avait-il assez de choix ?`                           | `Le choix était beaucoup plus limité que ce qui avait été annoncé.`                          | 与宣传形成对比。                    |
| `Les besoins alimentaires étaient-ils pris en compte ?` | `Il y avait très peu d’options végétariennes malgré les promesses du programme.`             | 可写活动没有兑现宣传。                 |
| `Quelle a été la conséquence ?`                         | `Nous sommes finalement repartis sans avoir réellement découvert les spécialités annoncées.` | 点明活动核心目标没有实现。               |

### 可直接背的句组

> **En outre, l’offre de nourriture était très décevante. Dès vingt heures, plusieurs stands n’avaient plus rien à servir. Les rares plats encore disponibles étaient froids, chers et servis en très petites portions.**

---

## 5. 音响、视线和场地问题

| 法文问题部分                               | 法文回答                                                                               | 解释                                    |
| ------------------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------- |
| `Comment était la qualité du son ?`  | `La qualité du son était médiocre.`                                                | `médiocre` 表示质量差、低于平均水平。              |
| `Pouviez-vous entendre la musique ?` | `Depuis le fond du terrain, il était presque impossible d’entendre les chanteurs.` | `il était impossible de + infinitif`。 |
| `Le son était-il stable ?`           | `Le son se coupait régulièrement pendant les concerts.`                            | `se couper` 可表示声音中断。                  |
| `Pouviez-vous voir la scène ?`       | `La scène était trop basse pour que tout le monde puisse voir correctement.`       | `trop… pour que + subjonctif`，结构稍高级。  |
| `Comment étaient les écrans ?`       | `Les écrans géants fonctionnaient mal et restaient parfois noirs.`                 | 很具体。                                  |
| `Y avait-il trop de monde ?`         | `Le site était tellement bondé qu’il était difficile de circuler.`                 | `tellement… que` 表示程度导致结果。            |
| `La salle était-elle confortable ?`  | `La salle était mal ventilée et la température était insupportable.`               | 适合室内节庆。                               |
| `Quelle a été la conséquence ?`      | `Nous n’avons presque rien vu du spectacle malgré le prix élevé de nos billets.`   | `malgré + nom` 表示尽管。                  |

### 可直接背的句组

> **Enfin, les conditions techniques étaient loin d’être satisfaisantes. Le son se coupait régulièrement et la scène était si basse que nous ne voyions presque rien. Il était donc difficile de profiter réellement du concert.**

---

## 6. 卫生、厕所和清洁问题

| 法文问题部分                                   | 法文回答                                                                                   | 解释                  |
| ---------------------------------------- | -------------------------------------------------------------------------------------- | ------------------- |
| `Les lieux étaient-ils propres ?`        | `La propreté du site laissait beaucoup à désirer.`                                     | 很常用的负面评价。           |
| `Y avait-il assez de poubelles ?`        | `Il n’y avait pas assez de poubelles, si bien que des déchets couvraient le sol.`      | `si bien que` 表示结果。 |
| `Comment étaient les toilettes ?`        | `Les toilettes étaient sales et rarement nettoyées.`                                   | 可用于大型户外活动。          |
| `Y avait-il assez de toilettes ?`        | `Seules quelques toilettes étaient disponibles pour des milliers de visiteurs.`        | 具体说明数量失衡。           |
| `Combien de temps fallait-il attendre ?` | `Il fallait attendre près de trente minutes pour utiliser les toilettes.`              | 直接呈现不便。             |
| `Y avait-il de l’eau ?`                  | `Certains lavabos ne fonctionnaient plus dès le début de la soirée.`                   | 具体故障。               |
| `Quelle a été la conséquence ?`          | `Cette situation a rendu l’expérience particulièrement désagréable pour les familles.` | 说明对家庭游客的影响。         |

### 可直接背的句组

> **La propreté du site représentait également un problème sérieux. Les poubelles débordaient, les toilettes étaient sales et il fallait attendre près de trente minutes pour y accéder.**

---

## 7. 工作人员和信息服务问题

| 法文问题部分                                    | 法文回答                                                                                       | 解释                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ | ----------------------------------- |
| `Le personnel était-il disponible ?`      | `Il était presque impossible de trouver un membre du personnel.`                           | 用于缺乏工作人员。                           |
| `Le personnel pouvait-il vous aider ?`    | `Les employés ne semblaient pas connaître le programme.`                                   | 表达工作人员自己也不清楚安排。                     |
| `Comment vous ont-ils répondu ?`          | `Lorsque nous avons demandé des renseignements, personne n’a pu nous répondre clairement.` | `demander des renseignements`：询问信息。 |
| `Le personnel était-il aimable ?`         | `Certains employés se montraient impatients et peu aimables.`                              | `se montrer + adjectif`：表现得怎样。      |
| `Les indications étaient-elles claires ?` | `Il manquait des panneaux pour indiquer les scènes, les sorties et les toilettes.`         | 指示牌问题很具体。                           |
| `La carte du festival était-elle utile ?` | `Le plan distribué à l’entrée était incomplet et difficile à comprendre.`                  | 适合文化节或大型音乐节。                        |
| `Les changements étaient-ils annoncés ?`  | `Les changements de programme n’étaient annoncés ni sur les écrans ni par les employés.`   | `ni… ni…` 表示既不……也不……                |
| `Quelle a été la conséquence ?`           | `Nous avons perdu beaucoup de temps à chercher les différentes activités.`                 | 说明信息差造成时间损失。                        |

### 可直接背的句组

> **Le manque d’information a aggravé la situation. Les changements d’horaires n’étaient annoncés nulle part et les employés étaient incapables de nous renseigner. Nous avons ainsi perdu beaucoup de temps à chercher les activités.**

## 8. 人群、安全和管理问题

| 法文问题部分                                            | 法文回答                                                                       | 解释                                 |
| ------------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------- |
| `Y avait-il trop de monde ?`                      | `Les organisateurs avaient manifestement vendu trop de billets.`           | `manifestement` 表示明显地，但仍属于基于现场的判断。 |
| `Était-il facile de circuler ?`                   | `La foule était si dense qu’il était presque impossible de circuler.`      | `dense` 形容人群密集。                    |
| `Les sorties étaient-elles accessibles ?`         | `Certaines sorties étaient bloquées par la foule.`                         | 安全问题。                              |
| `Le contrôle était-il suffisant ?`                | `Il y avait trop peu d’agents de sécurité pour gérer autant de visiteurs.` | 具体说明人手不足。                          |
| `Vous sentiez-vous en sécurité ?`                 | `À plusieurs moments, je ne me suis pas senti en sécurité.`                | 可以直接表达个人感受。                        |
| `Les enfants pouvaient-ils circuler facilement ?` | `Le site n’était pas adapté aux jeunes enfants.`                           | 家庭节庆可用。                            |
| `Quelle a été la conséquence ?`                   | `Nous avons préféré quitter le festival avant la fin.`                     | 安全问题足以导致提前离场。                      |

## 9. 活动内容与宣传不符

| 法文问题部分                                           | 法文回答                                                                                 | 解释                       |
| ------------------------------------------------ | ------------------------------------------------------------------------------------ | ------------------------ |
| `Le festival correspondait-il à la publicité ?`  | `L’événement ne correspondait pas du tout à sa publicité.`                           | 总体判断。                    |
| `Le programme était-il aussi riche qu’annoncé ?` | `Le programme était beaucoup moins varié que prévu.`                                 | `moins… que prévu`：比预期少。 |
| `Les artistes annoncés étaient-ils présents ?`   | `Plusieurs artistes présentés sur l’affiche n’étaient finalement pas présents.`      | 可写宣传误导。                  |
| `Les activités étaient-elles ouvertes ?`         | `De nombreux ateliers étaient fermés sans explication.`                              | 文化节、家庭节适用。               |
| `Les spectacles duraient-ils longtemps ?`        | `Certains spectacles ne duraient qu’une dizaine de minutes.`                         | `ne… que` 表示只有。          |
| `La qualité était-elle satisfaisante ?`          | `Les animations semblaient improvisées et peu préparées.`                            | `improvisé`：临时拼凑。        |
| `Quelle a été la conséquence ?`                  | `J’ai eu le sentiment d’avoir payé pour un programme qui n’existait pas réellement.` | 有力度，但仍保持个人感受框架。          |

# Chunk 5：后果弹药库

“不满意”不能只停留在情绪上。后果可以分成时间损失、金钱损失、体验损失、身体不适和最终行动。

## 1. 时间损失

| 法文问题部分                                       | 法文回答                                                                        | 解释                            |
| -------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------- |
| `Quelle a été la conséquence de l’attente ?` | `Nous avons perdu plus d’une heure à l’entrée.`                             | 最直接。                          |
| `Qu’avez-vous manqué ?`                      | `Nous avons manqué le début du spectacle principal.`                        | `manquer quelque chose` 不加介词。 |
| `Avez-vous profité des activités ?`          | `Nous avons passé davantage de temps à attendre qu’à profiter du festival.` | 比较结构 `davantage de… que de…`。 |
| `Avez-vous vu tout le programme ?`           | `Nous n’avons pu assister qu’à deux activités.`                             | `ne… que` 表示只参加了两个。           |

## 2. 金钱损失

| 法文问题部分                                 | 法文回答                                                                               | 解释                                              |
| -------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------- |
| `Le billet valait-il son prix ?`       | `Le festival ne valait absolument pas le prix demandé.`                            | `valoir le prix`：值这个价格。                         |
| `Avez-vous dû dépenser davantage ?`    | `Nous avons dû dépenser beaucoup plus que prévu pour manger et boire.`             | `plus que prévu`：比计划更多。                         |
| `Avez-vous regretté votre achat ?`     | `J’ai regretté d’avoir acheté un billet aussi cher.`                               | `regretter d’avoir + participe passé`：后悔已经做了某事。 |
| `Avez-vous demandé un remboursement ?` | `Après l’annulation du concert, plusieurs visiteurs ont demandé un remboursement.` | 可用于场次取消。                                        |

## 3. 体验损失

| 法文问题部分                                        | 法文回答                                                                                  | 解释                                      |
| --------------------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------- |
| `Avez-vous pu profiter du festival ?`         | `Il était impossible de profiter pleinement de l’événement.`                          | 通用后果。                                   |
| `Votre soirée a-t-elle été agréable ?`        | `Ces problèmes ont complètement gâché notre soirée.`                                  | `gâcher` 是 T2 很实用的动词。                   |
| `Avez-vous découvert les activités prévues ?` | `Nous sommes repartis sans avoir découvert la plupart des activités annoncées.`       | `sans avoir + participe passé` 表示没做成某事。 |
| `Votre impression finale ?`                   | `Au lieu d’être un moment de détente, cette sortie est devenue une source de stress.` | 对比清楚。                                   |

## 4. 身体和情绪后果

| 法文问题部分                                 | 法文回答                                                                    | 解释                 |
| -------------------------------------- | ----------------------------------------------------------------------- | ------------------ |
| `Comment vous sentiez-vous ?`          | `À la fin de la journée, nous étions épuisés et frustrés.`              | 简单稳妥。              |
| `La chaleur vous a-t-elle dérangé ?`   | `La chaleur et le manque d’eau nous ont rapidement fatigués.`           | 主语是两项，所以用复数 `ont`。 |
| `L’attente était-elle stressante ?`    | `L’incertitude concernant les horaires a créé beaucoup de frustration.` | 适合节目变动。            |
| `Avez-vous perdu votre enthousiasme ?` | `Notre enthousiasme a rapidement disparu.`                              | 短句，可用于段落收束。        |

## 5. 最终行动

| 法文问题部分                                 | 法文回答                                                                      | 解释                            |
| -------------------------------------- | ------------------------------------------------------------------------- | ----------------------------- |
| `Êtes-vous resté jusqu’à la fin ?`     | `Nous avons finalement quitté le festival avant la fin.`                  | 明确行为结果。                       |
| `Souhaitez-vous y retourner ?`         | `Je ne pense pas y retourner l’année prochaine.`                          | `y` 代替 `à ce festival`。       |
| `Recommandez-vous l’événement ?`       | `Je ne peux pas recommander cet événement à mes lecteurs.`                | 面向博客读者。                       |
| `Qu’attendez-vous des organisateurs ?` | `J’espère que les organisateurs tireront les leçons de cette expérience.` | `tirer les leçons de`：从中吸取教训。 |

# Chunk 6：情绪词不能单独使用，要与事实绑定

| 法文问题部分                       | 法文回答                                                                      | 解释                                      |
| ---------------------------- | ------------------------------------------------------------------------- | --------------------------------------- |
| `J’étais déçu.`              | `J’étais déçu, car deux concerts avaient été annulés sans explication.`   | `déçu` 后面补原因。                           |
| `J’étais frustré.`           | `Après une heure d’attente sans information, j’étais vraiment frustré.`   | 情绪来自等待和信息缺失。                            |
| `J’étais mécontent.`         | `J’étais mécontent de la qualité du service.`                             | `être mécontent de quelque chose`。      |
| `J’étais surpris.`           | `J’ai été surpris par le manque d’organisation.`                          | `être surpris par quelque chose`。       |
| `J’étais irrité.`            | `Le bruit, la chaleur et l’attente ont fini par m’irriter.`               | `finir par + infinitif` 表示最终导致。         |
| `J’étais inquiet.`           | `Je me suis senti inquiet lorsque la foule a bloqué les sorties.`         | 与安全场景绑定。                                |
| `J’ai regretté ma décision.` | `À la fin de la soirée, j’ai regretté d’avoir participé à cet événement.` | `regretter d’avoir participé` 表示后悔已经参加。 |

# Chunk 7：结尾和推荐弹药库

老师板书中的第四部分是 `Recommandations`。当前题目不要求你必须推荐，因此可以写负面建议、保留意见或改进要求。

## 1. 明确不推荐

| 法文问题部分                                           | 法文回答                                                                    | 解释                                               |
| ------------------------------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------ |
| `Recommandez-vous ce festival ?`                 | `Je ne recommande donc pas ce festival.`                                | 最直接。                                             |
| `Quelle est votre opinion finale ?`              | `Dans son organisation actuelle, cet événement ne mérite pas son prix.` | 指出问题在当前组织水平，而不是永久否定。                             |
| `Conseillerez-vous ce festival à vos lecteurs ?` | `Je conseille à mes lecteurs de choisir un autre événement.`            | `conseiller à quelqu’un de faire quelque chose`。 |
| `Souhaitez-vous y retourner ?`                   | `Pour ma part, je ne compte pas y retourner l’année prochaine.`         | `compter + infinitif`：打算。                        |
| `Le festival vaut-il le déplacement ?`           | `À mon avis, ce festival ne vaut pas le déplacement.`                   | `valoir le déplacement`：值得专程前往。                  |

## 2. 有条件地推荐

| 法文问题部分                                     | 法文回答                                                                                    | 解释                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------- | ----------------------------------------- |
| `Le festival pourrait-il être amélioré ?`  | `Le concept est intéressant, mais l’organisation doit être profondément améliorée.`     | 承认创意不错，但执行失败。                             |
| `Pourriez-vous le recommander plus tard ?` | `Je pourrais recommander ce festival si les problèmes d’organisation étaient corrigés.` | 条件式结构。                                    |
| `Quel conseil donner aux visiteurs ?`      | `Si vous souhaitez malgré tout y aller, arrivez tôt et apportez de l’eau.`              | 面向读者给现实建议。                                |
| `Quel conseil donner aux familles ?`       | `Je déconseille cet événement aux familles avec de jeunes enfants.`                     | `déconseiller quelque chose à quelqu’un`。 |

## 3. 给主办方建议

| 法文问题部分                                    | 法文回答                                                                                                   | 解释                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------- |
| `Que devraient faire les organisateurs ?` | `Les organisateurs devraient mieux contrôler le nombre de billets vendus.`                             | 用条件式提出建议。                       |
| `Comment réduire l’attente ?`             | `Ils devraient ouvrir davantage d’entrées et recruter plus de personnel.`                              | 两个具体动作。                         |
| `Comment améliorer l’information ?`       | `Les changements de programme devraient être annoncés immédiatement.`                                  | 被动语态，适合正式建议。                    |
| `Comment améliorer le confort ?`          | `Il faudrait installer plus de toilettes, de poubelles et de zones de repos.`                          | `il faudrait + infinitif` 表示应当。 |
| `Comment améliorer les prix ?`            | `Les prix de la nourriture devraient être plus raisonnables.`                                          | 直接且安全。                          |
| `Comment restaurer la confiance ?`        | `Les organisateurs devraient rembourser les visiteurs lorsque des spectacles importants sont annulés.` | 建议与具体问题对应。                      |

## 4. 正式收束

| 法文问题部分                             | 法文回答                                                                                            | 解释                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------- |
| `Quelle conclusion générale ?`     | `Au final, cette expérience a été une véritable déception.`                                     | 总体评价。                             |
| `Quel espoir exprimer ?`           | `J’espère que les organisateurs tiendront compte des critiques des visiteurs.`                  | `tenir compte de`：考虑。             |
| `Quel changement souhaitez-vous ?` | `Avec une meilleure organisation, ce festival pourrait pourtant devenir un événement agréable.` | 结尾不必只有否定，可以指出改善空间。                |
| `Quelle décision personnelle ?`    | `Pour l’instant, je préfère ne pas renouveler cette expérience.`                                | `renouveler une expérience`：再次体验。 |

### 三套可直接使用的结尾

| 法文问题部分                    | 法文回答                                                                                                                                                                                  | 解释          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `Conclusion directe`      | `Au final, je ne recommande pas ce festival. Les prix étaient trop élevés et l’organisation ne permettait pas de profiter correctement des activités.`                                | 简洁、任务完成清楚。  |
| `Conclusion constructive` | `Le concept de ce festival reste intéressant, mais de nombreuses améliorations sont nécessaires. J’espère que les organisateurs écouteront les visiteurs avant la prochaine édition.` | 负面但不情绪化。    |
| `Conclusion avec conseil` | `Je déconseille actuellement cet événement aux familles. Si vous décidez malgré tout d’y aller, arrivez tôt et prévoyez de l’eau ainsi qu’un repas.`                                  | 面向读者给出实际建议。 |

# 易错点表

| 法文问题部分                                         | 法文回答                                      | 解释                                                          |
| ---------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------- |
| `participer un festival`                       | `participer à un festival`                | `participer` 后必须接 `à`。                                      |
| `assister un concert`                          | `assister à un concert`                   | 法语 `assister à` 表示观看、出席。                                    |
| `attendre pour une heure`                      | `attendre pendant une heure`              | 持续多久用 `pendant`；`attendre` 后不加 `pour`。                      |
| `attendre à un bon festival`                   | `s’attendre à un bon festival`            | `attendre` 是等待；`s’attendre à` 才是预期。                         |
| `j’étais très décevant`                        | `j’étais très déçu`                       | 人感到失望用 `déçu`；事物令人失望用 `décevant`。                           |
| `le festival m’a déçu`                         | `Le festival m’a déçu.`                   | 如果说话者是男性，过去分词不配合，因为 `m’` 是放在前面的直接宾语，但其性别是男性；女性说话者写 `déçue`。 |
| `les prix étaient très chers`                  | `les prix étaient très élevés`            | 法语更自然地说“价格高”是 `prix élevés`；`cher` 更常修饰商品。                  |
| `une nourriture chère`                         | `des plats chers / des prix élevés`       | `nourriture chère` 可以理解，但考试中应尽量写清楚商品或价格。                    |
| `à cause de l’organisation était mauvaise`     | `à cause de la mauvaise organisation`     | `à cause de` 后接名词，不直接接完整句。                                  |
| `parce que la mauvaise organisation`           | `parce que l’organisation était mauvaise` | `parce que` 后接主语＋动词。                                        |
| `malgré il pleuvait`                           | `malgré la pluie / bien qu’il pleuve`     | `malgré` 后接名词；接完整从句要换结构。                                    |
| `nous avons raté à le concert`                 | `nous avons manqué le concert`            | `manquer quelque chose` 直接接宾语。                              |
| `je ne recommande pas à ce festival`           | `je ne recommande pas ce festival`        | `recommander quelque chose à quelqu’un`；被推荐的东西是直接宾语。        |
| `je déconseille ce festival pour les familles` | `je déconseille ce festival aux familles` | `déconseiller quelque chose à quelqu’un`。                   |
| `il y avait beaucoup des personnes`            | `il y avait beaucoup de personnes`        | 数量词 `beaucoup de` 后不用 `des`。                                |
| `plusieurs des activités`                      | `plusieurs activités`                     | `plusieurs` 直接接复数名词。                                        |
| `la plupart des activité`                      | `la plupart des activités`                | `la plupart des + 名词复数`。                                    |
| `les informations n’étaient pas clairs`        | `les informations n’étaient pas claires`  | `information` 是阴性，复数形容词写 `claires`。                         |

| `Comment parler d’une foule excessive ?`       | `Le site était tellement bondé qu’il était difficile de circuler.`                             | 程度＋结果。       |
| `Comment dire que l’expérience a été gâchée ?` | `Ces problèmes ont complètement gâché notre soirée.`                                           | 主体段收束句。      |
| `Comment exprimer un regret ?`                 | `J’ai regretté d’avoir acheté un billet aussi cher.`                                           | 后悔已经完成的动作。   |
| `Comment dire que vous êtes parti tôt ?`       | `Nous avons finalement quitté le festival avant la fin.`                                       | 行为后果。        |
| `Comment donner un avis final ?`               | `Au final, je ne recommande pas ce festival dans son organisation actuelle.`                   | 清楚回应推荐问题。    |
| `Comment proposer une amélioration ?`          | `Les organisateurs devraient mieux informer les visiteurs et recruter davantage de personnel.` | 条件式建议。       |
| `Comment terminer de manière constructive ?`   | `J’espère qu’ils tiendront compte de ces critiques avant la prochaine édition.`                | 不空泛，指向下一届。   |

| 法文问题部分                                    | 法文回答                                                                                              | 解释                                |

| `Combien de problèmes faut-il choisir ?`  | `Deux problèmes principaux suffisent.`                                                            | 每个问题写完整，比列出五个没有证据的问题更有效。          |
| `Comment développer chaque problème ?`    | `[jugement] + [fait précis] + [conséquence]`                                                      | 例如：组织混乱＋等一小时＋错过演出。                |

# Chunk 1：理由段的四层结构

一个完整的理由段，可以拆成四层。考试中不必每层都单独占一句，但逻辑必须存在。

| 法文问题部分                        | 法文回答                                                                     | 解释                       |
| ----------------------------- | ------------------------------------------------------------------------ | ------------------------ |
| **1. `Constat général`**      | `Tout d’abord, l’organisation à l’entrée était catastrophique.`          | 先指出问题类别：组织、价格、节目、卫生、服务等。 |
| **2. `Preuve concrète`**      | `Nous avons dû attendre plus d’une heure sous la pluie.`                 | 用时间、价格、数量、取消事件等事实证明判断。   |
| **3. `Conséquence`**          | `À cause de ce retard, nous avons manqué le début du concert principal.` | 解释这个问题怎样损害了你的体验。         |
| **4. `Réaction ou jugement`** | `Pour un billet aussi cher, cette situation était inacceptable.`         | 最后把事实转化为明确评价。            |

组合后：

> **Tout d’abord, l’organisation à l’entrée était catastrophique. Nous avons dû attendre plus d’une heure sous la pluie. À cause de ce retard, nous avons manqué le début du concert principal. Pour un billet aussi cher, cette situation était inacceptable.**

这四层也可以压缩成两句：

> **Tout d’abord, l’entrée était très mal organisée : nous avons attendu plus d’une heure sous la pluie et manqué le début du concert. Pour un billet de soixante dollars, cette situation était inacceptable.**

## 四层结构的可替换零件

| 法文问题部分                                 | 法文回答                                                                           | 解释                                  |
| -------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------- |
| `Comment annoncer un problème ?`       | `Le premier problème concernait l’organisation.`                               | 比 `Il y avait un problème` 更清楚。     |
| `Comment donner un exemple ?`          | `Par exemple, nous avons attendu quarante-cinq minutes pour acheter de l’eau.` | `par exemple` 后接具体事件。               |
| `Comment préciser un fait ?`           | `Une seule entrée était ouverte pour plusieurs centaines de personnes.`        | 具体数量使批评可信。                          |
| `Comment introduire une conséquence ?` | `À cause de cela, nous avons manqué une partie du spectacle.`                  | `à cause de cela` 指代前面的负面事实。        |
| `Comment exprimer le résultat ?`       | `Cela a rendu l’expérience particulièrement stressante.`                       | `cela` 指代整个前文事件。                    |
| `Comment donner son jugement ?`        | `Une telle organisation est difficilement acceptable.`                         | `une telle organisation` 表示这样的组织方式。 |
| `Comment relier au prix payé ?`        | `Compte tenu du prix du billet, je m’attendais à un service bien meilleur.`    | 将价格和期待关联。                           |
| `Comment montrer la déception ?`       | `Cette situation a fortement contribué à ma déception.`                        | 用于段尾收束。                             |

# Chunk 2：原因、解释和证据的连接方式

## 1. `parce que`：后接完整句

| 法文问题部分                                    | 法文回答                                                                   | 解释                                        |
| ----------------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------- |
| `Pourquoi étiez-vous déçu ?`              | `J’étais déçu parce que plusieurs concerts avaient été annulés.`       | `parce que` 后面必须有主语和变位动词。                 |
| `Pourquoi l’attente était-elle longue ?`  | `L’attente était très longue parce qu’une seule entrée était ouverte.` | 解释事实原因。                                   |
| `Pourquoi avez-vous quitté le festival ?` | `Nous sommes partis tôt parce que la foule devenait dangereuse.`       | 原因在后面。                                    |
| `Peut-on écrire parce que + nom ?`        | `Non : parce que l’organisation était mauvaise.`                       | 不能写 `parce que la mauvaise organisation`。 |

## 2. `car`：补充解释

| 法文问题部分                               | 法文回答                                                                                       | 解释                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------ | --------------------- |
| `Comment expliquer une attente ?`    | `J’attendais ce festival avec impatience, car plusieurs artistes connus étaient annoncés.` | `car` 常放在第二分句，引出解释。   |
| `Comment justifier un jugement ?`    | `Les prix me semblaient injustifiés, car les portions étaient minuscules.`                 | 适合书面文章。               |
| `Car peut-il commencer une phrase ?` | `En théorie oui, mais il vaut mieux l’utiliser après une première proposition.`            | 考试中最安全的是放在逗号之后。       |
| `Quelle différence avec parce que ?` | `Les deux expriment la cause, mais car sonne plus explicatif et plus écrit.`               | 当前作文中二者都能用，不必强行区分得太细。 |

---

## 3. `en effet`：证明前一句

| 法文问题部分                           | 法文回答                                                            | 解释                         |
| -------------------------------- | --------------------------------------------------------------- | -------------------------- |
| `L’organisation était mauvaise.` | `En effet, nous avons attendu plus d’une heure avant d’entrer.` | 第一句提出判断，`en effet` 后给证据。   |
| `Les prix étaient excessifs.`    | `En effet, une petite bouteille d’eau coûtait six dollars.`     | 用事实证明“贵”。                  |
| `Le programme était décevant.`   | `En effet, trois spectacles ont été annulés.`                   | 证明节目安排差。                   |
| `Quelle est sa fonction ?`       | `En effet confirme ou explique l’idée précédente.`              | 它不是普通的“然后”，而是“确实，因为事实是……”。 |

安全公式：

> **[评价]。En effet, [具体证据]。**

例如：

> **La gestion des horaires était désastreuse. En effet, aucun spectacle n’a commencé à l’heure.**

## 4. `à cause de`：后接名词

| 法文问题部分                                           | 法文回答                                                                   | 解释                                                                                     |
| ------------------------------------------------ | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `À cause de quoi avez-vous manqué le concert ?`  | `À cause de la longue attente, nous avons manqué le début du concert.` | `à cause de + 名词或名词组`。                                                                 |
| `Pourquoi avez-vous quitté le site ?`            | `Nous sommes partis à cause de la chaleur.`                            | 不能在后面直接接完整句。                                                                           |
| `Comment reprendre toute la phrase précédente ?` | `À cause de cela, nous avons dû partir plus tôt.`                      | `cela` 指代整个前文情况。                                                                       |
| `Quelle erreur éviter ?`                         | `❌ À cause de l’organisation était mauvaise.`                          | 应改成 `à cause de la mauvaise organisation`，或 `parce que l’organisation était mauvaise`。 |

## 5. `en raison de`：更正式的原因表达

| 法文问题部分                                      | 法文回答                                                                           | 解释                      |
| ------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------- |
| `Pourquoi la séance a-t-elle été annulée ?` | `La séance a été annulée en raison d’un problème technique.`                   | 比 `à cause de` 更正式、更中性。 |
| `Pourquoi l’accès était-il difficile ?`     | `L’accès était difficile en raison du nombre excessif de visiteurs.`           | 适合文章文体。                 |
| `Est-ce toujours négatif ?`                 | `Non, mais il est souvent utilisé pour présenter une cause de manière neutre.` | 当前题目中通常接负面原因。           |

## 1. `donc`：直接结果

| ---------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------- |
| `Le concert a commencé en retard.` | `Nous avons donc manqué le dernier train.`                                | `donc` 放在变位动词后或主语后都可以。                          |
| `Les stands étaient fermés.`       | `Nous avons donc dû manger à l’extérieur du site.`                        | 表示直接后果。                                         |
| `Comment placer donc ?`            | `Nous avons donc quitté le festival.`                                     | 主语＋助动词＋`donc`＋过去分词，是很常见的位置。                     |
| `Peut-on écrire Donc au début ?`   | `Oui, mais dans cette作文, la position interne est souvent plus naturelle.` | 例如 `Donc, nous sommes partis` 也对，但频繁句首使用会显得口语化。 |

## 2. `c’est pourquoi`：因此

| 法文问题部分                              | 法文回答                                                             | 解释                   |
| ----------------------------------- | ---------------------------------------------------------------- | -------------------- |
| `Les conditions étaient mauvaises.` | `C’est pourquoi nous avons quitté le festival avant la fin.`     | 表示前因导致后果，适合连接两个完整句子。 |
| `Les prix étaient trop élevés.`     | `C’est pourquoi plusieurs visiteurs sont allés manger ailleurs.` | 比单独用 `donc` 更完整。     |
| `Quelle ponctuation ?`              | `Phrase précédente. C’est pourquoi + proposition.`               | 最安全的是另起一句。           |

## 3. `si bien que`：结果达到某种程度

| 法文问题部分                                 | 法文回答                                                                                | 解释                                |
| -------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------- |
| `Il n’y avait pas assez de poubelles.` | `Il n’y avait pas assez de poubelles, si bien que le sol était couvert de déchets.` | 前面是原因，后面是自然结果。                    |
| `La foule était très dense.`           | `La foule était très dense, si bien qu’il était difficile de circuler.`             | 很适合描述现场问题。                        |
| `Quel mode verbal utiliser ?`          | `L’indicatif.`                                                                      | `si bien que` 后面通常使用直陈式，因为结果已经发生。 |

## 4. `tellement… que`：程度导致结果

| 法文问题部分                         | 法文回答                                                                      | 解释                            |
| ------------------------------ | ------------------------------------------------------------------------- | ----------------------------- |
| `Le site était très bondé.`    | `Le site était tellement bondé qu’il était impossible de circuler.`       | `tellement + adjectif + que`。 |
| `La musique était très forte.` | `La musique était tellement forte que nous ne pouvions plus parler.`      | 程度导致结果。                       |
| `L’attente était très longue.` | `L’attente était tellement longue que plusieurs personnes ont abandonné.` | 可以直接将形容词升级成结果结构。              |
| `Quelle erreur éviter ?`       | `❌ tellement que le site était bondé`                                     | `tellement` 要修饰形容词、副词、动词或数量。  |

## 5. `trop… pour`：过于……以至于不能……

| 法文问题部分                                    | 法文回答                                                               | 解释                                                 |
| ----------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------- |
| `La salle était très petite.`             | `La salle était trop petite pour accueillir tous les visiteurs.`   | 主句与不定式执行者一致时用 `pour + infinitif`。                  |
| `Le son était très faible.`               | `Le son était trop faible pour être entendu au fond de la salle.`  | 被动不定式。                                             |
| `Le site était très éloigné.`             | `Le site était trop éloigné pour y aller facilement sans voiture.` | `y` 指代那个地点。                                        |
| `Quelle différence avec tellement… que ?` | `Trop… pour exprime une impossibilité ou une limite.`              | `tellement… que` 只表示结果；`trop… pour` 更强调“太……所以做不到”。 |

## 6. `ce qui`：前面整件事导致……

| 法文问题部分                                            | 法文回答                                                                                                | 解释                                         |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `Le concert a commencé avec une heure de retard.` | `Le concert a commencé avec une heure de retard, ce qui a irrité le public.`                        | `ce qui` 指代前面整个事实，并在后句作主语。                 |
| `Deux séances ont été annulées.`                  | `Deux séances ont été annulées, ce qui a fortement déçu les visiteurs.`                             | 很适合 T2。                                    |
| `Les horaires changeaient constamment.`           | `Les horaires changeaient constamment, ce qui rendait l’organisation difficile à suivre.`           | 前面整件事使后果发生。                                |
| `Pourquoi utiliser ce qui ?`                      | `Parce que le pronom reprend toute la proposition précédente et devient le sujet du verbe suivant.` | 后面是 `ce qui a déçu`，因为“这件事”是 `a déçu` 的主语。 |

## 7. `ce qui / ce que` 的区别

| 法文问题部分                                          | 法文回答                                                            | 解释                                          |
| ----------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| `Le retard a déçu les visiteurs.`               | `Le concert a commencé en retard, ce qui a déçu les visiteurs.` | 后面的动词缺主语，所以用 `ce qui`。                      |
| `Je n’ai pas apprécié cette situation.`         | `Le manque d’information est ce que j’ai le moins apprécié.`    | 后面的 `j’ai apprécié ___` 缺直接宾语，所以用 `ce que`。 |
| `Quelle forme est la plus utile dans cette作文 ?` | `ce qui`                                                        | T2 常写“某件事造成了某种后果”，所以 `ce qui` 使用频率更高。       |

# Chunk 4：补充、递进、转折与让步

## 1. 添加理由

| 法文问题部分                                   | 法文回答                                                      | 解释                                       |
| ---------------------------------------- | --------------------------------------------------------- | ---------------------------------------- |

## 5. `même si`：即使、虽然＋直陈式

| `Le festival était connu, mais il était mal organisé.`               | `Bien que le festival soit connu, il était très mal organisé.`          | 当前水平可以使用，但不是必须。           |

# Chunk 5：评价强度——从客观到强烈

负面作文需要明确立场，但不必每句都写 `très mauvais`。可以根据证据强弱选择不同程度。

| 法文问题部分                         | 法文回答                                              | 解释                    |
| ------------------------------ | ------------------------------------------------- | --------------------- |
| `Une critique modérée`         | `L’organisation pourrait être améliorée.`         | 比较温和，适合问题不严重。         |
| `Une critique claire`          | `L’organisation était insuffisante.`              | 明确指出没有达到要求。           |
| `Une critique forte`           | `L’organisation laissait beaucoup à désirer.`     | 非常适合评论文章。             |
| `Une critique très forte`      | `L’organisation était catastrophique.`            | 需要后面有足够严重的事实支撑。       |
| `Un service moyen`             | `Le service était décevant.`                      | 最普通的负面评价。             |
| `Un service très mauvais`      | `Le service était totalement inacceptable.`       | 应配合严重问题，如安全、欺骗或大规模取消。 |
| `Des prix un peu hauts`        | `Les prix étaient assez élevés.`                  | 程度较轻。                 |
| `Des prix trop hauts`          | `Les prix étaient excessifs.`                     | 明确超出合理范围。             |
| `Une mauvaise expérience`      | `L’expérience n’a pas répondu à mes attentes.`    | 中性、稳妥。                |
| `Une très mauvaise expérience` | `Cette expérience a été une véritable déception.` | 适合结尾。                 |

## 避免重复 `très`

| 法文问题部分             | 法文回答                                | 解释                                     |
| ------------------ | ----------------------------------- | -------------------------------------- |
| `très mauvais`     | `médiocre / décevant / insuffisant` | 根据具体对象替换。                              |
| `très cher`        | `excessif / hors de prix`           | `hors de prix` 偏口语；作文中 `excessif` 更稳。  |
| `très plein`       | `bondé`                             | 形容场地挤满人。                               |
| `très sale`        | `dans un état déplorable`           | 后者更强烈，适合厕所、场地。                         |
| `très long`        | `interminable`                      | `une attente interminable`，表示漫长得像没有尽头。 |
| `très déçu`        | `profondément déçu`                 | 书面一些。                                  |
| `très désorganisé` | `chaotique`                         | `une organisation chaotique`。          |
| `très désagréable` | `particulièrement pénible`          | 用于等待、炎热、拥挤等体验。                         |

# Chunk 6：时间顺序与时态选择

## 1. 复合过去时：发生并完成的事件

| 法文问题部分                        | 法文回答                                              | 解释        |
| ----------------------------- | ------------------------------------------------- | --------- |
| `Qu’avez-vous fait ?`         | `J’ai participé à un festival de musique.`        | 主要事件。     |
| `Qu’est-ce qui s’est passé ?` | `Le concert a commencé avec une heure de retard.` | 已完成的具体事件。 |
| `Qu’avez-vous décidé ?`       | `Nous avons quitté le festival avant la fin.`     | 做出的决定。    |
| `Qu’est-ce qui a changé ?`    | `La pluie a commencé vers vingt heures.`          | 突然发生的新事件。 |

## 2. 未完成过去时：背景、状态和持续情况

| 法文问题部分                           | 法文回答                                         | 解释              |
| -------------------------------- | -------------------------------------------- | --------------- |
| `Comment était le site ?`        | `Le site était bondé.`                       | 描述状态。           |
| `Que faisait la foule ?`         | `La foule avançait très lentement.`          | 持续中的动作。         |

| `Quelle était votre attente ?`   | `J’attendais cet événement avec impatience.` | 描述参加前持续存在的心理状态。 |
| `Comment étaient les employés ?` | `Les employés semblaient débordés.`          | 描述状态或印象。        |

| ------------------------------------------- | --------------------------------------------------------------------------- | ---------------- |

## 4. 三种时态放在同一段

| 法文问题部分                       | 法文回答                                                                                                  | 解释                |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- | ----------------- |
| `Avant le festival`          | `J’avais acheté mon billet deux mois à l’avance, car plusieurs artistes connus avaient été annoncés.` | 愈过去时：更早的购票和宣传。    |
| `Le décor et l’état du lieu` | `À mon arrivée, le site était déjà bondé et les files avançaient très lentement.`                     | 未完成过去时：现场背景和持续状态。 |

完整组合：

> **J’avais acheté mon billet deux mois à l’avance, car plusieurs artistes connus avaient été annoncés. Pourtant, à mon arrivée, le site était déjà bondé et les files avançaient très lentement. Après une heure d’attente, nous avons enfin réussi à entrer.**

# Chunk 8：文章中的“平衡评价”

负面题目要求不满意，但不等于必须把所有方面都写成坏的。承认一个优点，再说明为什么总体仍不满意，文章会更可信。

| 法文问题部分                                 | 法文回答                                                                                                     | 解释                          |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------- |
| `Les artistes étaient-ils bons ?`      | `Les artistes étaient talentueux, mais la mauvaise qualité du son empêchait de les apprécier.`           | 承认表演者不错，问题在技术执行。            |
| `Le concept était-il intéressant ?`    | `Le concept était original. Toutefois, l’organisation n’était pas à la hauteur.`                         | `être à la hauteur`：达到应有水平。 |
| `Le lieu était-il agréable ?`          | `Le parc était magnifique, mais il n’était pas adapté à une foule aussi nombreuse.`                      | 区分场地本身和活动管理。                |
| `Certains plats étaient-ils bons ?`    | `Quelques plats étaient délicieux, mais les portions étaient trop petites et les prix excessifs.`        | 局部优点不改变总体判断。                |
| `Le programme était-il prometteur ?`   | `Le programme semblait très riche, mais de nombreuses activités ont été annulées.`                       | 宣传与执行之间的落差。                 |
| `Pourquoi utiliser une评价 équilibrée ?` | `Elle montre que la conclusion repose sur une comparaison, pas seulement sur une réaction émotionnelle.` | 更像真实评论。                     |

可直接使用：

> **Même si certains concerts étaient réussis, l’organisation générale était trop mauvaise pour que nous puissions réellement profiter de la soirée.**

更安全的版本：

> **Certains concerts étaient réussis, mais l’organisation générale nous a empêchés de profiter pleinement de la soirée.**

# 核心语法表

| 法文问题部分                               | 法文回答                                                                        | 解释                                      |
| ------------------------------------ | --------------------------------------------------------------------------- | --------------------------------------- |
| `parce que + ?`                      | `parce que + sujet + verbe`                                                 | `parce que l’entrée était fermée`。      |
| `à cause de + ?`                     | `à cause de + nom`                                                          | `à cause de la pluie`。                  |
| `en raison de + ?`                   | `en raison de + nom`                                                        | 比 `à cause de` 更正式。                     |
| `malgré + ?`                         | `malgré + nom`                                                              | `malgré le prix élevé`。                 |
| `même si + ?`                        | `même si + indicatif`                                                       | `même si le concept était intéressant`。 |
| `bien que + ?`                       | `bien que + subjonctif`                                                     | 不熟悉虚拟式时不必强用。                            |
| `tellement + adjectif + que`         | `Le site était tellement bondé qu’il était difficile de circuler.`          | 程度导致结果。                                 |
| `trop + adjectif + pour + infinitif` | `La salle était trop petite pour accueillir tout le monde.`                 | 太……以至于不能……                              |
| `ce qui + verbe`                     | `Le concert a été annulé, ce qui a déçu le public.`                         | `ce qui` 在后句作主语。                        |
| `au lieu de + infinitif`             | `Nous avons attendu au lieu de profiter du festival.`                       | 表示没有做本应做的事。                             |
| `sans + infinitif`                   | `Les organisateurs ont annulé la séance sans prévenir les visiteurs.`       | 两个动作主语相同。                               |
| `sans avoir + participe passé`       | `Nous sommes repartis sans avoir vu le spectacle principal.`                | 表示离开时某件事仍未完成。                           |
| `regretter de + infinitif passé`     | `J’ai regretté d’avoir acheté ce billet.`                                   | 后悔已经做过的动作。                              |
| `s’attendre à + nom`                 | `Je m’attendais à une meilleure organisation.`                              | 表示预料或期待。                                |
| `empêcher quelqu’un de faire`        | `La foule nous empêchait de circuler.`                                      | 阻止某人做某事。                                |
| `permettre à quelqu’un de faire`     | `L’organisation ne permettait pas aux visiteurs de profiter des activités.` | 允许某人做某事。                                |

# 易错点表

| 法文问题部分                                                | 法文回答                                                                     | 解释                                        |
| ----------------------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------- |
| `À cause que le concert était annulé`                 | `Parce que le concert était annulé / À cause de l’annulation du concert` | `à cause de` 后接名词；完整句用 `parce que`。       |
| `Malgré il pleuvait`                                  | `Malgré la pluie / Même s’il pleuvait`                                   | `malgré` 后不能直接接变位句。                       |
| `Le festival était tellement beaucoup de monde`       | `Il y avait tellement de monde qu’il était difficile de circuler.`       | 数量结构是 `tellement de + nom`。               |
| `Le site était trop bondé que…`                       | `Le site était tellement bondé que… / trop bondé pour…`                  | `trop` 不直接搭配 `que`。                       |
| `Ce que a déçu les visiteurs`                         | `Ce qui a déçu les visiteurs`                                            | 后面的动词缺主语，所以用 `ce qui`。                    |
| `Cela m’a fait très déçu`                             | `Cela m’a beaucoup déçu / Cela m’a rendu très déçu`                      | `décevoir quelqu’un` 直接表达使某人失望。           |
| `Cela a rendu l’expérience à être mauvaise`           | `Cela a rendu l’expérience désagréable.`                                 | `rendre + nom + adjectif`，不加 `à être`。    |
| `Nous avons empêché de profiter`                      | `Cela nous a empêchés de profiter du festival.`                          | `empêcher quelqu’un de faire`，必须有被阻止的人。   |
| `Nous avons pu seulement voir deux concerts`          | `Nous n’avons pu voir que deux concerts.`                                | `ne… que` 是更自然的“只”。                       |
| `Le festival ne vaut pas de prix`                     | `Le festival ne valait pas le prix du billet.`                           | `valoir le prix` 表示值这个价。                  |
| `J’ai regretté acheter le billet`                     | `J’ai regretté d’avoir acheté le billet.`                                | `regretter de`；已经完成的动作使用不定式过去式。           |
| `Les informations ont manqué`                         | `Il manquait des informations / Les informations étaient insuffisantes.` | “信息不足”不直接写 `les informations ont manqué`。 |
| `Le programme n’a pas suivi`                          | `Le programme n’a pas été respecté.`                                     | 法语通常说“节目安排没有被遵守”。                         |
| `Les organisateurs n’ont pas informé les changements` | `Les organisateurs n’ont pas informé les visiteurs des changements.`     | `informer quelqu’un de quelque chose`。    |
| `Cela a donné une mauvaise expérience`                | `Cela a rendu l’expérience désagréable / Cela a gâché l’expérience.`     | 避免英语式 `donner une expérience`。            |

# 做题流程

| 步骤     | 法文问题部分                                                  | 解释                                                                   |
| ------ | ------------------------------------------------------- | -------------------------------------------------------------------- |
| **1**  | `Quel festival vais-je choisir ?`                       | 音乐节、美食节或电影节三选一。不要写到一半再改变活动类型。                                        |
| **2**  | `Quelle était mon attente avant d’y aller ?`            | 选择一个期待：著名艺术家、丰富节目、外国美食、家庭活动。                                         |
| **3**  | `Quels sont mes deux principaux problèmes ?`            | 只选两个最容易举证的问题。                                                        |
| **4**  | `Quel fait précis prouve chaque problème ?`             | 为每个问题准备一个数字、时间、取消事件或现场细节。                                            |
| **5**  | `Quelle conséquence chaque problème a-t-il provoquée ?` | 错过演出、额外花钱、提前离场、无法享受活动。                                               |
| **6**  | `Quel est mon jugement final ?`                         | 不推荐、有条件推荐、希望主办方改进。                                                   |
| **7**  | `Quels connecteurs vais-je utiliser ?`                  | 固定 `Tout d’abord → En effet → De plus → À cause de cela → Au final`。 |
| **8**  | `Quels temps faut-il choisir ?`                         | 具体事件用复合过去时；背景状态用未完成过去时；更早宣传或购票用愈过去时。                                 |
| **9**  | `Ai-je écrit une preuve après chaque jugement ?`        | 圈出所有 `mauvais, cher, décevant, désorganisé`，检查后面是否有证据。               |
| **10** | `Le texte compte-t-il entre 120 et 150 mots ?`          | 目标 130—140 词。过长先删第三个问题，不要删核心证据链。                                     |

| `Comment parler d’une expérience gâchée ?`       | `Ces problèmes ont complètement gâché notre soirée.`                                      | 主体段收束。        |

| `Comment donner une recommandation finale ?`     | `Je ne recommande pas ce festival dans son organisation actuelle.`                        | 明确最终态度。       |
| `Comment proposer des améliorations ?`           | `Les organisateurs devraient recruter plus de personnel et mieux informer les visiteurs.` | 具体、可执行。       |
| `Comment terminer l’article ?`                   | `J’espère qu’ils tiendront compte de ces critiques avant la prochaine édition.`           | 建设性结尾。        |

# 本批结论

| 法文问题部分                                                | 法文回答                                                                    | 解释                                   |
| ----------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| `Quelle est l’unité minimale d’un bon argument ?`     | `[jugement] + [preuve] + [conséquence]`                                 | 只有评价没有事实，不构成充分理由。                    |
| `Quelle quatrième couche peut renforcer l’argument ?` | `[réaction ou évaluation personnelle]`                                  | 说明为什么你认为该问题不可接受。                     |
| `Quels connecteurs suffisent pour une作文 complète ?`   | `Tout d’abord, en effet, de plus, à cause de cela, cependant, au final` | 覆盖顺序、证明、补充、结果、转折和结尾。                 |
| `Quelle structure causale faut-il distinguer ?`       | `parce que + phrase / à cause de + nom`                                 | 这是最容易出现的结构错误之一。                      |
| `Comment éviter une作文只有情绪？`                           | `Remplacer les adjectifs vagues par des faits mesurables.`              | 不写“等了很久”，写“等了一个小时”；不写“很贵”，写“一瓶水六美元”。 |

| `Que se passe-t-il si le sujet change ?`             | `Une rédaction mémorisée devient difficile à adapter.`                                                                                                           | 背的是音乐节，但题目变成电影节时，很多句子无法直接使用。  |

| `Que faut-il préparer sans le mémoriser mot à mot ?` | `Deux ou trois histoires complètes.`                                                                                                                             | 音乐节、美食节、电影节各准备一套事实组合。         |
| `Quelle est l’unité de mémorisation idéale ?`        | `Un bloc de deux ou trois phrases.`                                                                                                                              | 比单句更有上下文，比整篇更容易替换。            |
| `Exemple de bloc stable`                             | `Tout d’abord, l’organisation était très mauvaise. En effet, nous avons dû attendre plus d’une heure. À cause de cela, nous avons manqué le début du spectacle.` | 只需替换等待时间和错过的活动。               |

# 易错点表

| 法文问题部分                                                     | 法文回答                                                           | 解释                                                                                                                       |
| ---------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `J’ai participé un festival.`                              | `J’ai participé à un festival.`                                | `participer à quelque chose`。                                                                                            |
| `Le festival était organisé dans Toronto.`                 | `Le festival était organisé à Toronto.`                        | 城市前用 `à`。                                                                                                                |
| `J’attendais pour ce festival.`                            | `J’attendais ce festival. / Je m’attendais à un bon festival.` | `attendre` 是等待某物；`s’attendre à` 是预期。                                                                                     |
| `L’expérience ne m’a pas satisfait.`                       | `L’expérience ne m’a pas satisfait.`                           | 男性说话者写 `satisfait`；女性说话者写 `satisfaite`，因为前置直接宾语 `m’` 指说话者。考试中也可避开配合问题，写 `Je n’ai pas été satisfait de cette expérience.` |
| `Les prix étaient très chers.`                             | `Les prix étaient très élevés / excessifs.`                    | “价格高”更自然地搭配 `élevé`。商品可以说 `un repas cher`。                                                                               |
| `Une bouteille coûtait de six dollars.`                    | `Une bouteille coûtait six dollars.`                           | `coûter + 金额`，金额前不加 `de`。                                                                                                |
| `Il y avait seulement une file.`                           | `Il n’y avait qu’une seule file.`                              | `ne… que` 是更自然的“只有”。                                                                                                     |
| `Nous avons manqué à le concert.`                          | `Nous avons manqué le concert.`                                | `manquer quelque chose` 直接接宾语。                                                                                           |
| `Beaucoup des visiteurs`                                   | `Beaucoup de visiteurs`                                        | 数量副词后使用 `de`。                                                                                                            |
| `Les toilettes étaient trop peu.`                          | `Les toilettes étaient trop peu nombreuses.`                   | 表示数量不足，需要 `peu nombreuses`。                                                                                              |
| `Les organisateurs devraient améliorer de l’organisation.` | `Les organisateurs devraient améliorer l’organisation.`        | `améliorer quelque chose` 直接接宾语。                                                                                         |
| `Je ne recommande pas à ce festival.`                      | `Je ne recommande pas ce festival.`                            | 活动是被推荐的对象，直接接在动词后。                                                                                                       |
| `Je n’irai pas encore.`                                    | `Je n’y retournerai pas.`                                      | 中文“不会再去”应使用 `retourner`；`encore` 容易变成“还没去”。                                                                              |
| `Dans la prochaine année.`                                 | `L’année prochaine.`                                           | “明年”不加介词。                                                                                                                |
| `À la prochaine édition, j’espère ils amélioreront…`       | `Lors de la prochaine édition, j’espère qu’ils amélioreront…`  | `espérer que + 完整从句`。                                                                                                    |

# 做题流程

| 步骤     | 法文问题部分                                              | 解释                                 |
| ------ | --------------------------------------------------- | ---------------------------------- |
| **1**  | `Je choisis un festival.`                           | 优先从音乐节、美食节、电影节中选择熟悉的一种。            |
| **2**  | `Je choisis une attente.`                           | 为什么买票：艺术家、电影、美食或家庭活动。              |
| **3**  | `Je choisis seulement deux problèmes principaux.`   | 推荐组合：排队＋价格；取消＋信息；食品不足＋卫生。          |
| **4**  | `Je donne une preuve précise pour chaque problème.` | 写一个小时、六美元、两场取消、只有一个入口等。            |
| **5**  | `J’écris une conséquence pour chaque problème.`     | 错过节目、浪费时间、花费增加、提前离场。               |
| **6**  | `Je décide si je recommande le festival.`           | 不推荐、有条件推荐或只不推荐给特定人群。               |
| **7**  | `Je remplis le modèle.`                             | 先把槽位填满，再调整连接词和重复。                  |
| **8**  | `Je vérifie les temps.`                             | 事件用复合过去时；背景状态用未完成过去时；更早发生的宣传用愈过去时。 |
| **9**  | `Je compte approximativement les mots.`             | 训练时用文字处理器的计词功能，正文目标为 130—140 词。    |
| **10** | `Je supprime ce qui n’aide pas la mission.`         | 超字数时先删第三个小问题和重复评价，不能删除两个主要原因的证据。   |

# 超字数时怎样删

| 法文问题部分                           | 法文回答                        | 解释                                                                  |
| -------------------------------- | --------------------------- | ------------------------------------------------------------------- |
| `Première suppression`           | 删除第三个补充问题                   | 保留两个完整理由。                                                           |
| `Deuxième suppression`           | 删除重复情绪句                     | `J’étais déçu` 与 `l’expérience était décevante` 留一个即可。              |
| `Troisième suppression`          | 合并地点和活动介绍                   | `J’ai participé à un festival de musique organisé à Toronto.`       |
| `Quatrième suppression`          | 合并证据和后果                     | `Après une heure d’attente, nous avons manqué le début du concert.` |
| `Ce qu’il ne faut pas supprimer` | 时间、活动类型、总体不满、两个理由、具体证据、最终评价 | 这些是文章的任务主干。                                                         |

# 全课最该进错题本的内容

| 错题类型      | 法文回答                                                                        | 解释                                              |
| --------- | --------------------------------------------------------------------------- | ----------------------------------------------- |
| 动词介词      | `participer à un festival`                                                  | `participer` 后不能直接接活动。                          |
| 两种“期待”    | `attendre un événement / s’attendre à une bonne organisation`               | 前者是等待，后者是预期。                                    |
| 人和事物的“失望” | `Je suis déçu. / L’expérience est décevante.`                               | `déçu` 描述人的感受；`décevant` 描述令人失望的事物。             |
| 原因结构      | `parce que + phrase / à cause de + nom`                                     | 不能写 `à cause de l’organisation était mauvaise`。 |
| 让步结构      | `malgré + nom / même si + indicatif`                                        | 不能写 `malgré il pleuvait`。                       |
| 结果结构      | `tellement… que / trop… pour`                                               | 不能混写成 `trop… que`。                              |
| 整句指代      | `Le concert a été annulé, ce qui a déçu le public.`                         | 后句缺主语，使用 `ce qui`。                              |
| 价格表达      | `Les prix étaient élevés. Une bouteille coûtait six dollars.`               | `coûter` 后的金额不加介词。                              |
| 错过活动      | `manquer le début du concert`                                               | 直接接宾语，不加 `à`。                                   |
| 推荐结构      | `recommander quelque chose à quelqu’un`                                     | `Je recommande ce festival à mes amis.`         |
| 不推荐结构     | `déconseiller quelque chose à quelqu’un`                                    | `Je déconseille ce festival aux familles.`      |
| 再次前往      | `Je ne compte pas y retourner.`                                             | 表示不准备再去。                                        |
| 改进结构      | `améliorer l’organisation / mieux informer les visiteurs`                   | 两个动词都直接接宾语。                                     |
| 字数安排      | `30 mots d’introduction + 70 mots de développement + 25 mots de conclusion` | 主体必须占最大篇幅。                                      |
