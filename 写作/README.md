# 写作素材：命名规则与来历

这个目录原先散在各课的 `L<n>/doc/写作/` 下，2026-08 前后整体挪到顶层，
同时**从「按课次」改成了「按任务」命名**。改名之后一个任务的题目、草稿、批改在一起，
不再需要先知道它是第几课讲的。

## 命名规则

`T<题型>.<该题型下的第几个任务> <任务简称> <版本或用途>.<ext>`

- `T1` / `T2` / `T3` ＝ TCF 写作的三个任务类型
- 后面的序号是**该题型下任务的编号**，与课次无关
- `1`、`1,2` 指文档里含第几版草稿；`批改` 指老师批改件；`弹药库` 指素材库
- `[TODO]` 前缀＝还没写

## 给后来的 agent

- **不要**按内容哈希去找"丢失"的写作文件就下结论。这一轮的重组既改名又改了载体
  （截图并进 docx），哈希搜索会一无所获，但内容其实还在。先看图/文件里**是什么**，
  再按任务简称去 `写作/` 找对应任务。
- `writing_coach/`、`docs/superpowers/`、`.omx/` 是另一条线的在建项目，不属于本目录的素材层。
