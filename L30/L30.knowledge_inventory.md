## Learning Mainlines

1. **告示与动作接口**：`laisser + objet`、`laisser + infinitif`、`il est interdit de`、`merci de`，重点是先整块识别表达功能，再谈字面义。
2. **场景词义、状态与限定**：`travail / travaux`、`promenade`、`réservé à/aux`、`ouvert`、`a ouvert au printemps`，重点是按场景和限定词读义，不自动脑补“只在……”。
3. **阅读排错与证据提取**：先排有问题的选项，再看共同介词、机翻碎片和同义替换，避免把“看起来像”当成证据。
4. **时间、通知与公司语境**：`avancer` / `reporter`、`service`、`prévenir` / `informer`、`nouvelles`，重点是日常办公与通知语境下的真实用法。
5. **职业语境与搭配记忆**：`démarrer une activité professionnelle`、`artisan` / `artiste`、`atelier`、`suivre + formation/cours/traitement`，最后收束到“按搭配簇记忆”的学习策略。

## High-Value Decision Families

- `laisser + objet` / `laisser + infinitif` / `se garer` / `stationner`：留下、任由与停车动作不能混读。
- `il est interdit de` / `merci de`：一个是禁止，一个是礼貌指令，都是告示整块接口。
- `réservé à/aux` / `ouvert` / `a ouvert au printemps`：专供关系、开放状态与时间信息要分开判断。
- `avancer` / `reporter` / `à l'avance`：提前、推迟与提前地是三种不同层级。
- `service` / `prévenir` / `informer`：公司语境里先判断“部门”还是“通知动作”。
- `les nouvelles`：在这里是近况、消息、updates，不是新闻节目。
- `artisan` / `artiste`：手艺人与艺术家不是一回事。
- `suivre + formation / cours / traitement`：高频搭配要成组记，不要拆成孤立义项。
