# L27 Knowledge Inventory

Source: `docker-data/outputs/L27/L27_final_working.md`

L27 的学习核心是把“介词接口”和“时态选择”从做题直觉整理成可复用的判断规则：`dont` 处理 de 关系，`faire du sport` 这类活动表达保留部分冠词；过去时里要区分背景/习惯/进行与明确持续时间；条件式则从构成、独立用法、si 句搭配一路延伸到 TCF 输出。

## Core Checkpoints

- `dont`：当从句里的隐藏关系是 `de + 先行词`，用 `dont`，包括 `rêver de`, `se souvenir de`, `avoir besoin de`, `avoir peur de` 和名词补语。
- `faire + partitif + activité`：体育/艺术活动说 `faire du sport`, `faire de la peinture`, `faire de la natation`，不要写 `faire le sport`。
- `passé composé` vs `imparfait`：没说清持续边界时可用背景性 `imparfait`；一旦说 `pendant toute la nuit/deux heures`，事件被边界化，用复合过去时。
- `imparfait`：覆盖过去习惯、背景/状态、过去进行，不要只记成一种中文标签。
- `futur proche` vs `futur simple`：可借英文 be going to / will 理解，但不要机械化成“确定性规则”。
- `être` 命令式：`sois / soyons / soyez`。

## Conditionnel Block

- 构成：futur simple 词根 + imparfait 词尾。
- 独立用法：`je voudrais`, `vous devriez` 可表达委婉，也可用于说话人的推测/距离。
- `si + imparfait -> conditionnel présent`：表达与现在事实相反，或未来低概率假设。
- `si + présent -> futur simple`：主将从现；和上一组条件句是两套锁死搭配。
- `sans + nom`：可以压缩表达条件，相当于一个没有展开的 si 从句。

## Production Use

TCF 输出里可以用条件式表达假设后果和建议，例如 `cela pourrait nuire aux résultats scolaires`。这类句型比直接断言更适合观点表达。
