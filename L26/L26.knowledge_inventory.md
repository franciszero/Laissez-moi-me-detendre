## 学习组

1. **中性代词 le**
   - 无性数变化。
   - 替代不定式、表语、整句事实。
   - 重点区分表语 `le` 与直宾 `le/la/les`。

2. **dont 名词补语**
   - `dont` = of which。
   - 后接名词短语时保留冠词：`dont les parents`, `dont l’auteur`。
   - 从句可看似完整，因为 `dont` 补的是从句里名词的 `de` 补语。

3. **副动词 en + 现在分词**
   - 现在分词：nous 现在时词干 + `-ant`。
   - 副动词三大状语：同时、方式/手段、条件。
   - 训练把低级并列句升级成一个谓语 + 一个状语。

4. **lequel 复合关系代词**
   - 处理其他介词 + 先行词。
   - 介词必须保留；`lequel` 按先行词性数变化。
   - `à + lequel` 系列有缩合：`auquel / à laquelle / auxquels / auxquelles`。
   - 可与 `où`、介词 + `qui` 有局部重合；优先简单自然表达。

5. **动词接口与高频纠错**
   - `intéresser` 的感兴趣者是直宾；`s’intéresser à` 才是“我对……感兴趣”的常用主语框架。
   - `assister à` 与 `à laquelle`。
   - `se tromper de`、`beaucoup de + plural count noun`、`avoir l’air` 配合。
